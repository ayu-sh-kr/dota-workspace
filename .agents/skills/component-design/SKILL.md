# Component Design

Use this skill when designing a reusable component and you need the right component pattern, structure, or subskill to use.
Keep this skill generic. Put specialized behavior in nested skills under this directory.

## Available Subskills

- `scroll/` - horizontal snap scroll, carousel, and slide-deck components
- `markdown-embeds/` - placing custom components inside markdown/tutorial content

## Selection Rule

If the task is about a specific component family, use the matching nested skill instead of stuffing the behavior here.
