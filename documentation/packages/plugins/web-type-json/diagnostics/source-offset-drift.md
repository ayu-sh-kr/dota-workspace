# Web-types source offset drift

The web-types generator records source locations for components and their properties so IDEs can navigate from generated HTML metadata back to TypeScript declarations.

## Issue

Repeated builds or scans could change the `source.offset` values in generated `web-types.json` even when the source files had not changed. The drift affected component metadata generated by the web-types plugin.

## Why it happened

The web-types plugin parses source files with SWC. SWC span positions are based on a process-wide `BytePos` counter rather than always being relative to the current file. `PropertyView` treated `property.span.start` as file-relative whenever it happened to be smaller than `sourceText.length`.

The first parse could therefore produce a local-looking offset, while a later parse produced a larger global position and activated the text-search fallback. Different paths produced different offsets for the same property.

## Fix

`main.ts` now passes the original source text, the parsed module's `ast.span.start`, and the local source index represented by that module start to `PropertyView.getSourceOffset()`. `PropertyView` normalizes the property span against that module context:

```text
file offset = property.span.start - ast.span.start + moduleStartLocalOffset
```

`moduleStartLocalOffset` is calculated from the source text by skipping leading whitespace and comments, matching the first token represented by the module span. SWC's relative byte distance is then converted to the source text's character offset so non-ASCII content before a property does not shift the generated location. The final anchor is the property identifier, matching the component class anchor convention.

This makes the offset relative to the source file regardless of how many SWC parses have already occurred in the process. Text matching remains a recovery path for callers that do not have the module span context.

The regression test parses the same source repeatedly and verifies that both parses return the same source offset.
