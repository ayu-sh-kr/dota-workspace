Every client build now removes the Node server generated by an earlier build before writing its own, following Vite's `emptyOutDir` convention. A non-`node` build therefore no longer leaves an out-of-date `dist-server` that points to client assets that no longer exist. Only a directory whose `server.mjs` carries the dota-ssr generated notice is removed.
